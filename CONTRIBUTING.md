# Contributing corrections

Corrections and reproducibility improvements are welcome.

For a useful issue or pull request, include:

1. The dataset and exact row, field or file.
2. The current value and proposed replacement.
3. A stable public source and its observation date.
4. Whether the change affects methodology, data or metadata.

Do not submit private data, scraped personal contact details, confidential material or claims that cannot be tied to public evidence. A correction is released only after it is reconciled with the official project version.
